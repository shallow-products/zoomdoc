# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and discuss constructively.
- No harassment, discrimination or personal attacks.
- Do not publish other people's private information without permission.

If you feel this is not being followed, tell the maintainers through a GitHub issue (use a private report on the Security tab for anything you do not want public). Maintainers may remove comments or restrict participation as appropriate.
